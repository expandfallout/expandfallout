### Notable base features (all worth keeping)
- **`SWEP.DynamicBloom`** — spread grows the longer you hold fire.
  `{Min, Max, Increase, Recovery, ShotsToStart, UtilShotReset}`. Present on 511 weapon entries.
- **`SWEP.Spread`** — `{AirMod, CrouchMod, IronSightsMod, VelocityMod}` situational multipliers.
  Jumping badly punished (`AirMod = 5` on the 9mm).
- **`SWEP.Events`** — timed reload sound scheduling: `{time, snd, typ}` keyed by `RELOAD_START` /
  `RELOAD_START_EMPTY`. Clean system.
- **`SWEP.RaceWorldOverride`** — *the integration point with the race system.* Per-race world model
  offset/angle/scale and attachment bone, so a 9mm looks right in a super mutant's hand vs a human's.
  Keys: `human`, `supermutant`, `nightkin`, `securitron`. **This is the piece most likely to break when
  we add races the weapons don't know about — needs a sane fallback.**
- **`SWEP.NVHoldType` / `AttackAnim` / `ReloadAnim` / `AttackAnimIS`** — New Vegas animation set names
  (`1hp`, `1hpreloada`, `1hpattack3`), driving the custom NV player animations.
- Ironsights: `IronSightsPos/Ang/FOV/Sensitivity/Crosshair`, `UseIronSightsRecoil`
- `LoweredPos`/`LoweredAng` for weapon-lowered state
- `KickUpVertical` / `KickUpHorizontal` recoil pattern
