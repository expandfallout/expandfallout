# UI Layer

**8,808 LOC** across two custom widget libraries in `schema/`. This is a full reskin — they did not use
NutScript's stock menus.

## `fallout_ui/` — the Pip-Boy / terminal aesthetic

**Screens:** `cl_charcreate`, `cl_charcustomize`, `cl_charload`, `cl_inventory`, `cl_mainmenu`,
`cl_menu`, `cl_newmenu`, `cl_special`, `cl_terminal`

**HUD:** `cl_fallout_hud.lua`, `cl_fallout.lua`

**Widgets (`vgui/`):** a complete `fo_*` reimplementation of Derma —
`fo_dbutton`, `fo_dcombobox`, `fo_dframe`, `fo_dgrid`, `fo_dlabel`, `fo_dmenu`, `fo_dpanel`,
`fo_dscrollpanel`, `fo_dtextentry`, `fo_dtexture`, `fo_dtexturebutton`, `fo_falloutnotice`, `fo_inv`,
`fo_updatelog`, `fo_utils`, plus `characterpanel`, `factionselect`, `searchablelistview`

`cl_special.lua` is the SPECIAL allocation screen; `cl_terminal.lua` is the Fallout terminal interface.

## `tgui/` — a second, plainer widget set

`tgui_button`, `tgui_checkbox`, `tgui_dmenu`, `tgui_dropdown`, `tgui_dscrollpanel`, `tgui_fonts`,
`tgui_frame`, `tgui_subpanel`, `tgui_textentry`, `tgui_valueentry`, plus `cl_tgui_requesters.lua`
(the confirm/prompt dialogs used by `/pk` and friends).

Two parallel widget libraries is duplication we shouldn't inherit — pick one and extend it.

## Helix differences that matter here

Helix has its own skin (`core/cl_skin.lua`), its own derma set in `gamemode/core/derma/`, and its
character creation is **step-based**: `ConfigureCharacterCreationSteps(panel)` plus
`panel:AddStep(vgui.Create("ixSomething"), priority)`. Their NutScript equivalent
(`panel:addStep(vgui.Create("nutCharacterAttribs"), 99)`) maps across cleanly — the SPECIAL step, race
selector and faction select all become Helix creation steps.

Helix's charcreate already handles the faction-to-model flow, so the appearance layering
(race → gender → ethnicity → face/hair/beard) is the part we'd add.

## Other client-side details worth noting

- `SCHEMA:ShouldDrawCrosshair()` hides the crosshair for `cw_*` and `wf_*` weapon classes
  (Customizable Weaponry / Weapon Framework) — leftovers from a previous weapon base, since they now use
  `ls_*`. Dead check.
- A `Think` hook runs `r_cleardecals` **every 300 seconds** server-wide and prints to console each time.
  Crude but effective for long-running RP servers; the console spam should go.
- `adv_crosshair` (543 LOC) is a fully user-editable crosshair.
- `damageview` (84 LOC) shows weapon damage on switch, applying `nut.rarity:dmgMult` for the display.
- `settingspage` (558 LOC) is an F1 preferences panel — Helix has `ix.option` built in, which covers most
  of this for free.
